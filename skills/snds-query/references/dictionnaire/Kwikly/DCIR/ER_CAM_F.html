CAM_ACT_CODCode activitéchar1Ce code permet, pour un même acte CCAM (même code acte CAM_PRS_IDE), de séparer les différentes activités constitutives de l’acte, par exemple de séparer l’activité chirurgicale (activité 1) de l’activité d’anesthésie (activité 4). Pour compter les actes, il faut tenir compte du code activité et du code phase de traitement afin de ne compter qu’une fois l’acte (et non, une fois au titre de l’acte chirurgical, en activité 1, et une fois au titre de l’anesthésie, en activité 4) ; le code descriptif détaillé d’un acte CCAM est constitué du triplet CAM_PRS_IDE (identifiant du code acte CCAM) + CAM_ACT_COD (code activité) + CAM_TRT_PHA (code phase de traitement).XXXXXXXX

CAM_QUA_DENLocalisation dentairechar32Cette zone n'est pas renseignée actuellement pour les dentistes. Avec la mise en oeuvre de la CCAM dentaire, chaque localisation dentaire devrait être renseignée sur 2 caractères, avec un maximum de 16 localisations dentaires (correspondant au 32 caractères de la longueur de la variable).
Une localisation dentaire correspondra soit à un numéro de dent (inclus les dents de lait), soit à une arcade (01, 02), soit à un quadrant (10, 20, 30, 40) ou soit à un sextant (03, 04, 05, 06, 07, 08).		XXXXXXXX
