BEN_RNG_GEMRang du bénéficiairenum8La règle de calcul du rang du bénéficiaire dans le SNIIRAM est la suivante :
- le rang de l’ouvreur de droits est toujours égal à 1,
- si un ayant droit a la même date de naissance que l’ouvreur de droits, son rang est égal à 2,
- un enfant né d’une naissance unique a un rang égal à 1,
- lorsqu’il y a des naissances multiples, chaque enfant est différencié par son rang (1 pour le 1er, 2 pour le second, …). Dans les faits, le rang n’est pas valorisé de la même manière pour chacun des régimes :
- pour le régime général, la règle de calcul du rang dans le SNIIRAM énoncée est appliquée ;
- pour le RSI, le rang est un numéro d’ordre séquentiel (ouvreur de droits = 0, 1er ayant droit = 1, 2ème ayant droit = 2, 3ème ayant droit = 3, etc…) ;
- pour la MSA, le rang du bénéficiaire est propre à chaque organisme : si dans le groupe familial, lors de l’ouverture des droits à la maladie dans l’organisme, un autre individu est déjà connu avec la même date de naissance, on lui attribue un rang égal à 2, sinon le rang est égal à 1.		XXXXXXXX

En effet, l’identifiant utilisé est le numéro de l’établissement dans lequel ils exercent. En l’absence de transmission d’information pour ces cas, le code spécialité est souvent renseigné à tort à la valeur 1 (et non "99-inconnue"). Il est donc conseillé de prendre en compte le mode d’exercice du PS (variables PSP_STJ_COD et PSE_STJ_COD) lorsque l’on étudie la spécialité.
Pour les médecins exerçant en milieu hospitalier, nous préconisons aux utilisateurs de forcer la spécialité à 99 au lieu de 1 dans leurs traitements.		XXXXXXXX
